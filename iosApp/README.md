# NoScroll+ iOS shell

This SwiftUI shell hosts the shared NoScroll+ Compose Multiplatform `ComposeApp` framework.

Create an Xcode iOS App target named `NoScroll+`, add `iosApp.swift` and `ContentView.swift`, and connect the generated `ComposeApp` framework from the `composeApp` iOS framework task. The shared entry point is `MainViewControllerKt.MainViewController()`.
